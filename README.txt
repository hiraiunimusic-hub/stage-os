STAGE OS 非公開セトリ版

公開用ファイルに曲名やメモは含まれていません。
index.html、manifest.webmanifest、sw.js をGitHub PagesなどHTTPSの静的ホスティングにアップロードしてください。
iPad Safariで開いて「メモを編集」から曲名・メモを入力し、保存します。内容はそのブラウザ内にのみ保存され、サーバーへ送信されません。
端末・ブラウザのデータ削除に備え、「設定を書き出す」でバックアップしてください。
注意：ブラウザ内保存は暗号化やパスワード保護ではありません。共有iPadには向きません。
オフライン利用はホーム画面追加後、ネット接続した状態で一度起動し、機内モードで確認してください。

V3: 編集画面で曲を追加・削除できます。既存のブラウザ保存データは引き継ぎます。GitHubに3ファイルを上書きアップロードしてください。
